# BÜHNE

[English](README.md) · [Deutsch](README.de.md) · [Русский](README.ru.md)

**Лёгкий, красивый и нативный видеоплеер для macOS — пара к торрент-клиенту [STRÖM](https://github.com/oskarreuss-create/strom).**

> STRÖM скачивает, BÜHNE проигрывает. Две программы сделаны как пара и выглядят одинаково. BÜHNE бесплатен, без ограничения по времени и без платной версии «Plus».

## Возможности
- MP4, M4V и MOV играют нативно (AVFoundation); MKV, AVI и всё остальное — через libmpv. Аппаратное декодирование.
- Панель управления в одну строку: перетаскивается в 6 позиций и сжимается вместе с окном вплоть до трёх кнопок.
- Позиция просмотра запоминается для каждого файла; фильм продолжается с того же места.
- Плейлист из папки (только видеофайлы), по желанию — на панели управления.
- Скорость 0,5–3×, дорожки звука и субтитров, формат кадра, обрезка, поворот, обнаружение чёрных полос, «картинка в картинке».
- Вид Liquid Glass, светлая / тёмная / авто тема, прозрачность стекла.
- Интерфейс на 6 языках: English (по умолчанию), Deutsch, Français, Italiano, Русский, Español.
- Клавиши: Пробел, ← → перемотка 10 с, ↑ ↓ громкость, F полный экран, M без звука, [ ] скорость, A / S дорожка звука / субтитров, ⌘O открыть, ⌘, настройки.

## Работает в паре со STRÖM
STRÖM — лёгкий BitTorrent-клиент для macOS с возможностью отключить раздачу. Скачать: [страница Releases](https://github.com/oskarreuss-create/strom/releases). Ссылка есть и в настройках BÜHNE.

Смотреть во время загрузки: нажмите Play в STRÖM, и BÜHNE откроет видео по мере скачивания. Перематывать дальше уже скачанной части нельзя.

## Требования
macOS 26 или новее, Apple Silicon и [mpv](https://mpv.io) из Homebrew:

```bash
brew install mpv
```

## Установка
1. Скачайте `Buehne-<версия>.zip` на странице [Releases](../../releases) и перенесите BÜHNE в «Программы».
2. Приложение не подписано сертификатом Apple Developer ID и не нотаризовано, поэтому при первом запуске macOS покажет предупреждение. Откройте *Системные настройки → Конфиденциальность и безопасность*, найдите BÜHNE и нажмите **Всё равно открыть**. Или выполните:

```bash
xattr -dr com.apple.quarantine /Applications/Buehne.app
```

## Сборка из исходников
Нужны Xcode (Swift 6.2) и `brew install mpv`.

```bash
swift test
./scripts/make-app.sh      # создаёт build/Buehne.app (подпись ad-hoc, только для локального использования)
```

Открыть файл из командной строки: `Buehne /path/to/file.mkv` или `buehne://open?path=...`. Подробнее: [BUEHNE_CONTRACT.md](BUEHNE_CONTRACT.md).

## Конфиденциальность
Без слежки, рекламы, cookies и аккаунтов; собственных сетевых запросов нет (кроме воспроизведения http/https-адреса, который вы сами открыли). Позиции просмотра и настройки остаются на вашем Mac. Единственная связь с интернетом — кнопка «Скачать STRÖM» в настройках, она открывает браузер.
